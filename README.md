# 随听

给本地音乐库做的 Windows 桌面播放器，第一版 0.1。

## 打开和使用

打开 `outputs/随听/随听.exe`。首次启动点击左下角 **添加音乐文件夹**，可以添加多个来源。
导入后双击歌曲，或者点击 **播放当前筛选**。

- 搜索支持歌曲、歌手、专辑、标签和完整路径；Ctrl+F 定位搜索框。
- 使用两个下拉框按标签、原文件夹筛选。
- Ctrl 或 Shift 多选歌曲，再批量添加标签、移除标签、收藏或取消收藏。
- 输入多个标签时用中文或英文逗号分隔。标签只存入本地资料库。
- “我的收藏”“最近加入（7天）”“还没听过”会随音乐库和播放历史更新。
- “播放队列”展示本轮从当前歌曲开始的剩余队列。双击其他分类的歌曲会重新生成队列。
- “播放规则”可设置近期降权天数、同一歌手间隔和收藏优先；保存后对下一轮智能随机生效。
- 支持顺序播放和单曲循环。本轮智能随机不重复；一轮结束后点击播放开始新一轮。
- 每次打开自动扫描已有来源，运行中每两分钟检查一次，也可以点击“重新扫描”。
- 听满 30 秒才计入历史；不足 60 秒的歌曲听满一半计入。暂停和跳过的时间不计入。

## 数据和文件

程序只读取音乐文件，不移动、重命名或修改音频。来源文件夹、标签、收藏、播放历史和设置保存在
`随听.exe` 同级的 `data/library.sqlite3`。把整个“随听”文件夹放在可写的位置。

备份时先关闭播放器，再复制整个 `data` 文件夹。音乐不包含在备份中，需要另行保留。
“文件失效”保留找不到的文件及其分类，恢复原路径后重新扫描即可。歌曲移动到新路径会当成新文件导入，
当前版本还没有自动匹配迁移标签的功能。扫描错误详情在 `data/scan-errors.txt`。

## 当前兼容范围

主要播放格式为 MP3、FLAC、OGG 和 WAV。AAC、M4A、WMA、Opus 也会尝试导入，是否能播放取决于具体编码，
不保证全部支持；加密音乐文件不支持。WAV 暂不支持拖动进度，其他格式的拖动精度取决于音频编码。
没有内嵌信息时，按“歌手 - 歌名”的文件名解析，专辑使用所在文件夹名称。

这是第一版，还没有歌词、封面展示、均衡器、桌面小窗和系统媒体键集成。
界面和播放流程已用生成的 WAV 文件验证，打包后的程序也已通过窗口、音频解码、收藏与历史记录检查。
随机队列已用 5000 首模拟歌曲验证。尚未使用你的真实音乐库或验证全部编码。

## 开发

源代码：`player.py`（窗口和播放），`library.py`（扫描、SQLite 和随机规则）。
需要 Python 3.12、pygame 2.5.2、mutagen 1.48.1。PyInstaller 用于打包。
开发依赖放在 `work/deps`，源码启动时自动加载这个目录。

```powershell
python -m pip install --target work/deps -r requirements.txt
python player.py
python -m unittest discover -s tests -p test_library.py -v
python tests/smoke_player.py
```

界面测试使用虚拟音频设备与临时生成的静音文件，不读取个人音乐。
